# Sistema de Invernadero Inteligente 

**Práctica 5 — Herencia y polimorfismo**
Aplicación de consola en Java.

## Descripción

Aplicación que representa de forma simplificada un invernadero inteligente. El sistema cuenta con sensores de temperatura del aire, humedad ambiental y humedad del suelo que registran mediciones simuladas y las interpretan según su tipo (baja, adecuada o alta). Con base en la humedad del suelo se decide si un sistema de riego debe activarse o permanecer inactivo.
